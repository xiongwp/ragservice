## World 1: Language Lab

High school: from user to builder of modern AI. Start where GPT starts: a model that predicts the next character, and a number that says how good it is.

## Learn

## 1. Characters, probabilities, loss

A character bigram model gives, for each character, the probability of each next character. Its quality is the average negative log-likelihood of the real next characters: the same crossentropy as before. Lower is better; GPT training curves show exactly this number going down.

```
import math print("guess among 27 characters at random:" , round(-math.log(1 / 27), 3))
```

## 2. Temperature

Before sampling, divide the scores by a temperature. Below 1 the model gets more confident and repetitive; above 1 it gets more creative and chaotic. Chatbots expose this exact setting.

```
import math scores = [2.0, 1.0, 0.0] for T in [0.5, 1.0, 2.0]: e = [math.exp(s / T) for s in scores] print(T, [round(x / sum(e), 2) for x in e])
```

## World 2: Optimizer Observatory

You used torch.optim.Adam as a black box. Open it. Optimizers decide how big and in which direction every step goes, and they are why modern networks train in hours instead of years.

## Learn

## 1. Momentum

Plain gradient descent forgets the past. Momentum keeps a running velocity: v = β·v + gradient, then x -= lr·v. Like a ball rolling downhill, it speeds up in steady directions and smooths out zigzags.

```
x, v = 10.0, 0.0 for step in range(5): g = 2 * (x - 3) v = 0.9 * v + g x = x - 0.05 * v print(step, round(x, 3))
```

## 2. Adam

Adam keeps two running averages: of the gradient (m) and of the squared gradient (v). The step is m ÷ √v, so every parameter gets its own step size. With bias correction for the first steps, it is the default optimizer almost everywhere.

```
print("m = b1*m + (1-b1)*g; v = b2*v + (1-b2)*g*g") print("x -= lr * m _ hat / (sqrt(v _ hat) + eps)")
```

## World 4: Paper Club

Research moves through papers. Learn to read them efficiently and to reproduce a result, the most respected skill in AI.

## Learn

## 1. The three-pass method

1. Pass 1 (10 minutes): title, abstract, figures, conclusion. What problem, what idea, what result?
2. Pass 2 (1 hour): read everything except proofs; mark what you do not understand.
3. Pass 3 (several hours): re-derive the key equations and re-implement the core.

Good first papers: LeNet (CNNs, 1998), ResNet (2015), "Attention Is All You Need" (2017).

```
questions = ["What problem?" , "What is new?" , "How is it tested?" , "What are the limits?"] for q in questions: print(q)
```

## Optimizer Observatory

## Three Optimizers Race

```
import math import matplotlib.pyplot as plt def f(x, y): return x * x + 10 * y * y def grad(x, y): return 2 * x, 20 * y def sgd(): x, y, hist = 5.0, 2.0, [] for t in range(60): gx, gy = grad(x, y) x -= 0.05 * gx y -= 0.05 * gy hist.append(f(x, y)) return hist def momentum(): x, y, vx, vy, hist = 5.0, 2.0, 0.0, 0.0, [] for t in range(60): gx, gy = grad(x, y) vx = 0.9 * vx + gx vy = 0.9 * vy + gy x -= 0.05 * vx y -= 0.05 * vy hist.append(f(x, y)) return hist def adam(): x, y = 5.0, 2.0 m = [0.0, 0.0] v = [0.0, 0.0] hist = [] for t in range(1, 61): g = grad(x, y) p = [x, y] for i in range(2): m[i] = 0.9 * m[i] + 0.1 * g[i] v[i] = 0.999 * v[i] + 0.001 * g[i] * g[i] mh = m[i] / (1 - 0.9 ** t) vh = v[i] / (1 - 0.999 ** t) p[i] -= 0.3 * mh / (math.sqrt(vh) + 1e-8) x, y = p hist.append(f(x, y)) return hist
```

```
runs = {"sgd": sgd(), "momentum": momentum(), "adam": adam()} for name, hist in runs.items(): plt.plot(list(range(1, 61)), hist, label=name) print(f"{name}: {hist[-1]:.4f}") plt.legend() plt.title("Optimizer race") plt.show()
```
