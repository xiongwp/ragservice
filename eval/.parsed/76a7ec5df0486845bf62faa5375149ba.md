## C++ Crossing

Informatics olympiads, from school contests to the IOI, are written in C++: it runs many times faster than Python. You already think like a programmer, so C++ is a new spelling for ideas you know. Every algorithm world after this one shows each idea in Python and in C++.

## Learn

## 1. Hello in two languages

C++ code lives inside int main() . Every statement ends with ; and blocks use { } instead of indentation. cout &lt;&lt; prints, and "\n" ends the line.

C++ must be compiled before it runs: clang++ -std=c++17 -O2 hello.cpp -o hello , then ./hello .

Python

```
print("Hello, IOI!") print(6 * 7)
```

C++

```
#include <iostream> using namespace std; int main() { cout << "Hello, IOI!" << "\n"; cout << 6 * 7 << "\n"; return 0; }
```

## 2. Types are fixed

In C++ every variable has a type that never changes: int (whole numbers up to about 2.1 billion), long long (up to about 9·10 18 ), double , string , bool .

The classic contest bug: an int that grows past 2,147,483,647 silently wraps around. When numbers can be big, use long long .

Python

```
a = 2000000000 b = 2000000000 print(a + b) print(7 // 2, 7 % 2)
```

C++

```
#include <iostream> using namespace std; int main() { long long a = 2000000000, b = 2000000000; cout << a + b << "\n"; // with int it would overflow cout << 7 / 2 << " " << 7 % 2 << "\n"; // int / int drops the decimals return 0; }
```

## 3. Reading input

Contest problems give their input as text. The usual format: a number n , then n numbers. Python reads a whole line with input() ; C++ reads one value at a time with cin &gt;&gt; , skipping spaces and newlines.

Python

```
n = int(input()) a = list(map(int, input().split())) print(sum(a))
```

C++

```
#include <iostream> #include <vector> using namespace std; int main() { int n; cin >> n; vector<long long> a(n); for (int i = 0; i < n; i++) cin >> a[i]; long long total = 0; for (long long x : a) total += x; cout << total << "\n"; return 0; }
```

## 4. if, for, while, functions

for i in range(n) becomes for (int i = 0; i &lt; n; i++) . Conditions need brackets. Functions declare the type of what they return and of each parameter. vector is C++'s list; sort(a.begin(), a.end()) sorts it.

Python

```
def is _ even(x): return x % 2 == 0 a = [5, 2, 8, 1] a.sort() for i in range(len(a)): if is _ even(a[i]): print(a[i], "even") else: print(a[i], "odd")
```

## C++

```
#include <iostream> #include <vector> #include <algorithm> using namespace std; bool is _ even(int x) { return x % 2 == 0; } int main() { vector<int> a = {5, 2, 8, 1}; sort(a.begin(), a.end()); for (int i = 0; i < (int)a.size(); i++) { if (is _ even(a[i])) cout << a[i] << " even" << "\n"; else cout << a[i] << " odd" << "\n"; } return 0; }
```

## World 1: Big-O Bay

A contest program must finish in about one second. A computer does roughly 10 8 simple C++ steps per second, so the first question for every problem is: how many steps will my idea take? That is time complexity, written with Big-O.

## Learn

## 1. Counting steps

One loop over n items: about n steps, O(n). A loop inside a loop: n² , O(n²). Halving each time: log₂ n steps, O(log n). For n = 100,000: O(n) is instant, O(n²) is 10 billion steps: far too slow. The animation shows how fast n² grows.

Python

```
import viz for n in range(1, 11): steps = [n, n * n] viz.bars(steps, {0: "green" , 1: "red"}, None, f"n = {n}: O(n) = {n} steps, O(n^2) = {n * n} steps") print("n = 100000:" , 100000, "vs" , 100000 ** 2)
```

C++

```
#include <iostream> using namespace std; int main() { long long n = 100000; cout << "n = 100000: " << n << " vs " << n * n << "\n"; return 0; }
```

## 2. Prefix sums: answer range sums instantly

Build pre[i] = sum of the first i numbers, once, in O(n). Then the sum from position l to r (1based) is pre[r] - pre[l-1] : one subtraction per question instead of a loop. Watch pre being built.

Python

```
import viz a = [3, -1, 4, 1, 5, 9, -2, 6] pre = [0] for i, x in enumerate(a): pre.append(pre[-1] + x) viz.cells(pre, {len(pre) - 1: "gold"}, {"i": len(pre) - 1}, f"pre[{i + 1}] = pre[{i}] + a[{i + 1}] = {pre[-1]}") l, r = 3, 6 viz.cells(pre, {r: "green" , l - 1: "red"}, {"r": r, "l-1": l - 1}, f"sum of a[{l}..{r}] = pre[{r}] - pre[{l - 1}] = {pre[r] - pre[l - 1]}") print(pre[r] - pre[l - 1])
```

C++

```
#include <iostream> #include <vector> using namespace std; int main() { vector<long long> a = {3, -1, 4, 1, 5, 9, -2, 6}; int n = a.size(); vector<long long> pre(n + 1, 0); for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + a[i]; int l = 3, r = 6; cout << pre[r] - pre[l - 1] << "\n"; return 0; }
```

## 3. Kadane: the best stretch in one pass

Maximum subarray sum: walk once, keeping cur = the best sum of a stretch that ends here. If cur becomes worse than starting fresh, start fresh. O(n) instead of trying every stretch in O(n²).

Python

```
import viz a = [-2, 1, -3, 4, -1, 2, 1, -5, 4] cur = best = a[0] for i in range(1, len(a)): cur = max(a[i], cur + a[i]) best = max(best, cur) viz.cells(a, {i: "gold"}, {"i": i}, f"cur = {cur}, best = {best}") print(best)
```

C++

```
#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> a = {-2, 1, -3, 4, -1, 2, 1, -5, 4}; int cur = a[0], best = a[0]; for (int i = 1; i < (int)a.size(); i++) { cur = max(a[i], cur + a[i]); best = max(best, cur); } cout << best << "\n"; return 0; }
```

## World 2: Sorting Springs

Sorting is the first step of countless algorithms. Watch five sorting methods work, see why some take n² steps and others n·log n, and learn when to write your own.

## Learn

## 1. Bubble sort: O(n²)

Compare neighbours and swap them if they are in the wrong order. After each pass the biggest remaining value has "bubbled" to the end. Red bars are being compared; green bars are in their final place.

Python

```
import viz a = [5, 1, 4, 2, 8, 3, 7, 6] n = len(a) done = {} for p in range(n - 1): for j in range(n - 1 - p): colors = dict(done) colors[j] = "red" colors[j + 1] = "red" viz.bars(a, colors, {"j": j}, f"compare {a[j]} and {a[j + 1]}") if a[j] > a[j + 1]: a[j], a[j + 1] = a[j + 1], a[j] done[n - 1 - p] = "green" viz.bars(a, {i: "green" for i in range(n)}, None, "sorted") print(*a)
```

C++

```
#include <iostream> #include <vector> #include <utility> using namespace std; int main() { vector<int> a = {5, 1, 4, 2, 8, 3, 7, 6}; int n = a.size(); for (int p = 0; p < n - 1; p++) for (int j = 0; j < n - 1 - p; j++) if (a[j] > a[j + 1]) swap(a[j], a[j + 1]); for (int x : a) cout << x << " "; cout << "\n"; return 0; }
```

## 2. Insertion sort: like sorting cards in your hand

Take the next card and slide it left until it sits in the right place. Very fast for lists that are almost sorted; O(n²) in the worst case.

Python

```
import viz a = [5, 1, 4, 2, 8, 3] for i in range(1, len(a)): j = i while j > 0 and a[j - 1] > a[j]: a[j - 1], a[j] = a[j], a[j - 1] viz.bars(a, {j - 1: "gold"}, {"i": i}, f"slide {a[j - 1]} left") j -= 1 print(*a)
```

C++

```
#include <iostream> #include <vector> #include <utility> using namespace std; int main() { vector<int> a = {5, 1, 4, 2, 8, 3}; for (int i = 1; i < (int)a.size(); i++) for (int j = i; j > 0 && a[j - 1] > a[j]; j--) swap(a[j - 1], a[j]); for (int x : a) cout << x << " "; cout << "\n"; return 0; }
```

## 3. Merge sort: divide and conquer, O(n log n)

Split the list in half, sort each half (by the same method), then merge the two sorted halves by repeatedly taking the smaller front item. There are log n levels of splitting and each level does n work: O(n log n). The coloured part is being merged.

Python

```
import viz a = [6, 3, 8, 1, 7, 2, 5, 4] def merge _ sort(lo, hi): if hi - lo <= 1: return mid = (lo + hi) // 2 merge _ sort(lo, mid) merge _ sort(mid, hi) left = a[lo:mid] right = a[mid:hi] i = j = 0 for k in range(lo, hi): if j >= len(right) or (i < len(left) and left[i] <= right[j]): a[k] = left[i] i += 1 else: a[k] = right[j] j += 1 viz.bars(a, {k: "gold" for k in range(lo, hi)}, None, f"merged positions {lo}..{hi - 1}") merge _ sort(0, len(a)) print(*a)
```

## C++

```
#include <iostream> #include <vector> using namespace std; vector<int> a = {6, 3, 8, 1, 7, 2, 5, 4}; void merge _ sort(int lo, int hi) { if (hi - lo <= 1) return; int mid = (lo + hi) / 2; merge _ sort(lo, mid); merge _ sort(mid, hi); vector<int> tmp; int i = lo, j = mid; while (i < mid || j < hi) { if (j >= hi || (i < mid && a[i] <= a[j])) tmp.push _ back(a[i++]); else tmp.push _ back(a[j++]); } for (int k = lo; k < hi; k++) a[k] = tmp[k - lo]; } int main() { merge _ sort(0, a.size()); for (int x : a) cout << x << " "; cout << "\n"; return 0; }
```

## 4. Quick sort and counting sort

Quick sort picks a pivot, moves smaller values to its left and bigger to its right, then sorts each side. On average O(n log n), and it is what sort() in C++ is built on. Counting sort works when values are small integers: count how many times each value appears, then write them out in order. O(n + max value).

## Python

```
import viz a = [3, 1, 4, 1, 5, 2, 2, 0, 3, 1] count = [0] * 6 for x in a: count[x] += 1 viz.cells(count, {x: "gold"}, None, f"count value {x}") out = [] for v in range(6): out += [v] * count[v] print(*out)
```

C++

```
#include <iostream> #include <vector> using namespace std; int main() { vector<int> a = {3, 1, 4, 1, 5, 2, 2, 0, 3, 1}; vector<int> count(6, 0); for (int x : a) count[x]++; vector<int> out; for (int v = 0; v < 6; v++) for (int k = 0; k < count[v]; k++) out.push _ back(v); for (int x : out) cout << x << " "; cout << "\n"; return 0; }
```





## World 3: Binary Search Bridge

Guess the Number from Year 1 was binary search: halve the range each time and you need only about 20 guesses for a million numbers. It is one of the most powerful ideas in contests, far beyond finding a number in a list.

## Learn

## 1. Searching a sorted list

Keep a range lo..hi where the target could be. Look at the middle: if it is too small, the target is to the right; if too big, to the left. Each step throws away half: O(log n).

Python

```
import viz a = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91] target = 23 lo, hi = 0, len(a) - 1 while lo <= hi: mid = (lo + hi) // 2 viz.cells(a, {mid: "gold"}, {"lo": lo, "mid": mid, "hi": hi}, f"a[{mid}] = {a[mid]}") if a[mid] == target: break elif a[mid] < target: lo = mid + 1 else: hi = mid - 1 print("found at index" , mid)
```

C++

```
#include <iostream> #include <vector> using namespace std; int main() { vector<int> a = {2, 5, 8, 12, 16, 23, 38, 56, 72, 91}; int target = 23, lo = 0, hi = a.size() - 1, mid = -1; while (lo <= hi) { mid = (lo + hi) / 2; if (a[mid] == target) break; else if (a[mid] < target) lo = mid + 1; else hi = mid - 1; } cout << "found at index " << mid << "\n"; return 0; }
```

## 2. Lower bound: the first position ≥ x

Often you need "the first position where a[i] ≥ x" . Use a half-open range [lo, hi): it always ends with lo = the answer, even when x is bigger than everything. In C++: lower \_ bound(a.begin(), a.end(), x) ; in Python: bisect.bisect \_ left(a, x) .

Python

```
import viz a = [1, 3, 3, 3, 5, 7, 9] x = 3 lo, hi = 0, len(a) while lo < hi: mid = (lo + hi) // 2 viz.cells(a, {mid: "gold"}, {"lo": lo, "mid": mid}, f"a[{mid}] = {a[mid]} {'< x: go right' if a[mid] < x else '>= x: go left'}") if a[mid] < x: lo = mid + 1 else: hi = mid print("first position with a[i] >= 3:" , lo)
```

C++

```
#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> a = {1, 3, 3, 3, 5, 7, 9}; int pos = lower _ bound(a.begin(), a.end(), 3) - a.begin(); cout << "first position with a[i] >= 3: " << pos << "\n"; return 0; }
```

## 3. Binary search on the answer

If you can answer "is H good enough?" with yes/no, and the answers look like yes, yes, yes, no, no as H grows, you can binary search on H itself, even when there is no list. Example: the highest saw height that still gives at least M metres of wood.

Python

```
import viz trees = [20, 15, 10, 17] need = 7 def wood(h): return sum(max(0, t - h) for t in trees) lo, hi = 0, max(trees) while lo < hi: mid = (lo + hi + 1) // 2 viz.bars(trees, {i: "gold" for i in range(len(trees)) if trees[i] > mid}, None, f"saw at {mid}: {wood(mid)} m of wood {'(enough)' if wood(mid) >= need else '(too little)'}") if wood(mid) >= need: lo = mid else: hi = mid - 1 print("best height:" , lo)
```

## C++

```
#include <iostream> #include <vector> #include <algorithm> using namespace std; vector<long long> trees = {20, 15, 10, 17}; long long wood(long long h) { long long s = 0; for (long long t : trees) s += max(0LL, t - h); return s; } int main() { long long need = 7, lo = 0, hi = *max _ element(trees.begin(), trees.end()); while (lo < hi) { long long mid = (lo + hi + 1) / 2; if (wood(mid) >= need) lo = mid; else hi = mid - 1; } cout << "best height: " << lo << "\n"; return 0; }
```





## World 4: Two-Pointer Tides

Two fingers walking along an array can replace a double loop. When both pointers only move forward, the total work is O(n), not O(n²).

## Learn

## 1. Pair sum in a sorted list

Put i at the start and j at the end. If a[i] + a[j] is too small, move i right; too big, move j left. Every step moves one pointer, so at most n steps.

## Python

```
import viz a = [1, 3, 4, 6, 8, 11, 15] k = 14 i, j = 0, len(a) - 1 while i < j: s = a[i] + a[j] viz.cells(a, {i: "gold" , j: "gold"}, {"i": i, "j": j}, f"{a[i]} + {a[j]} = {s} {'found!' if s == k else ('too small' if s < k else 'too big')}") if s == k: break elif s < k: i += 1 else: j -= 1 print(a[i], a[j])
```

C++

```
#include <iostream> #include <vector> using namespace std; int main() { vector<int> a = {1, 3, 4, 6, 8, 11, 15}; int k = 14, i = 0, j = a.size() - 1; while (i < j) { int s = a[i] + a[j]; if (s == k) break; if (s < k) i++; else j--; } cout << a[i] << " " << a[j] << "\n"; return 0; }
```

## 2. The sliding window

Find the longest stretch whose sum stays at most S (all numbers positive). Grow the window on the right; while it is too heavy, shrink it from the left. Each item enters and leaves the window once: O(n).

Python

```
import viz a = [2, 1, 3, 2, 4, 1, 1, 2] S = 6 left = 0 total = 0 best = 0 for right in range(len(a)): total += a[right] while total > S: total -= a[left] left += 1 best = max(best, right - left + 1) viz.cells(a, {k: "green" for k in range(left, right + 1)}, {"L": left, "R": right}, f"window sum {total}, best length {best}") print(best)
```

C++

```
#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { vector<int> a = {2, 1, 3, 2, 4, 1, 1, 2}; int S = 6, left = 0, total = 0, best = 0; for (int right = 0; right < (int)a.size(); right++) { total += a[right]; while (total > S) total -= a[left++]; best = max(best, right - left + 1); } cout << best << "\n"; return 0; }
```





## World 5: Recursion Ruins

A recursive function solves a problem by calling itself on smaller versions of it. With it you can try every possibility (backtracking), split problems in half (divide and conquer), and avoid repeating work (memoisation).

## Learn

## 1. The call tree

fib(n) = fib(n-1) + fib(n-2) . Each call makes two more calls, so the calls form a tree. Watch how many times the same values are computed again and again: plain recursion here takes exponential time.

## Python

```
import viz parent = [] labels = [] def fib(n, p): me = len(parent) parent.append(p) labels.append(f"f{n}") viz.tree(parent, {me: "gold"}, f"call fib({n})" , labels) if n < 2: return n return fib(n - 1, me) + fib(n - 2, me) print(fib(5, -1), "calls:" , len(parent))
```

## C++

```
#include <iostream> using namespace std; int calls = 0; int fib(int n) { calls++; if (n < 2) return n; return fib(n - 1) + fib(n - 2); } int main() { int r = fib(5); cout << r << " calls: " << calls << "\n"; return 0; }
```

## 2. Memoisation: remember the answers

Store each answer the first time you compute it, and look it up next time. fib(40) goes from about 300 million calls to 40. This idea is the door to dynamic programming.

Python

```
memo = {} def fib(n): if n < 2: return n if n not in memo: memo[n] = fib(n - 1) + fib(n - 2) return memo[n] print(fib(40)) print(fib(90))
```

C++

```
#include <iostream> #include <vector> using namespace std; vector<long long> memo(100, -1); long long fib(int n) { if (n < 2) return n; if (memo[n] != -1) return memo[n]; return memo[n] = fib(n - 1) + fib(n - 2); } int main() { cout << fib(40) << "\n" << fib(90) << "\n"; return 0; }
```

## 3. Backtracking: try, go deeper, undo

To list every ordering of 1..n: choose a number that is not used yet, go deeper, then undo the choice and try the next one. The same pattern solves Sudoku, N-Queens and many search problems.

Python

```
import viz n = 3 path = [] used = [False] * (n + 1) def go(): viz.cells(path + [" _ "] * (n - len(path)), {len(path) - 1: "gold"} if path else None, None, "choose" if len(path) < n else "complete: " + " " .join(map(str, path))) if len(path) == n: print(*path) return for x in range(1, n + 1): if not used[x]: used[x] = True path.append(x) go() path.pop() used[x] = False go()
```

## C++

```
#include <iostream> #include <vector> using namespace std; int n = 3; vector<int> path; vector<bool> used(4, false); void go() { if ((int)path.size() == n) { for (int i = 0; i < n; i++) cout << path[i] << (i + 1 < n ? " " : "\n"); return; } for (int x = 1; x <= n; x++) { if (used[x]) continue; used[x] = true; path.push _ back(x); go(); path.pop_ back(); used[x] = false; } } int main() { go(); return 0; }
```

## 4. Fast power: divide and conquer

a n = (a n/2 )² when n is even, and a · a n-1 when odd. That is O(log n) multiplications instead of n. Contests ask for huge powers modulo 10 9 +7, so keep reducing with % .

Python

```
MOD = 10 ** 9 + 7 def power(a, n): if n == 0: return 1 half = power(a, n // 2) result = half * half % MOD if n % 2 == 1: result = result * a % MOD return result print(power(2, 10), power(3, 200))
```

C++

```
#include <iostream> using namespace std; const long long MOD = 1000000007; long long power(long long a, long long n) { if (n == 0) return 1; long long half = power(a, n / 2); long long result = half * half % MOD; if (n % 2 == 1) result = result * a % MOD; return result; } int main() { cout << power(2, 10) << " " << power(3, 200) << "\n"; return 0; }
```





## World 6: Stack &amp; Queue Station

A stack is a pile of plates: last in, first out. A queue is a line at the shop: first in, first out. These two simple structures power bracket checking, undo buttons, BFS, and clever O(n) tricks.

## Learn

## 1. Stack: checking brackets

Read the text left to right. Push every opening bracket. For a closing bracket, the top of the stack must be its partner: pop it. At the end the stack must be empty.

## Python

```
import viz text = "([]{()})" pairs = {")": "(" , "]": "[" , "}": "{"} stack = [] ok = True for ch in text: if ch in "([{": stack.append(ch) elif not stack or stack[-1] != pairs[ch]: ok = False break else: stack.pop() viz.cells(stack if stack else ["empty"], {len(stack) - 1: "gold"} if stack else None, None, f"read {ch}") print("balanced" if ok and not stack else "not balanced")
```

C++

```

## 3. Monotonic stack: next greater element

## World 7: Greedy Gardens

A greedy algorithm makes the choice that looks best right now and never changes its mind. Sometimes that is provably optimal and beautifully fast. Sometimes it is wrong. The skill is knowing which.

## 1. Activity selection: earliest finish first

You want to attend as many events as possible, and they must not overlap. Sort by end time, and always take the next event that starts after the last one you took ended. Finishing early leaves the most room for the rest.

## World 8: BFS Burrows

Mazes, maps and networks are searched with two methods. BFS spreads out in rings, like a wave: it finds the shortest path when every step costs the same. DFS goes as deep as it can, then backs up: it is perfect for exploring and counting regions.

## Learn

## 1. BFS: the wave

Start from S with distance 0 in a queue. Take the front cell; every neighbour not visited yet gets distance + 1 and joins the back of the queue. Cells are reached in order of distance, so the first time you reach E, that distance is the shortest.

## Python

```
from collections import deque import viz maze = ["S..#.... " , " .#.#.##. " , " .#...#.. " , " .####.#. " , " ......#E"] h, w = len(maze), len(maze[0]) dist = [[-1] * w for _ in range(h)] dist[0][0] = 0 q = deque([(0, 0)]) while q: r, c = q.popleft() for dr, dc in [(1, 0), (-1, 0), (0, 1), (0, -1)]: nr, nc = r + dr, c + dc if 0 <= nr < h and 0 <= nc < w and maze[nr][nc] != "#" and dist[nr][nc] == -1: dist[nr][nc] = dist[r][c] + 1 q.append((nr, nc)) grid = [[maze[i][j] if maze[i][j] == "#" else (dist[i][j] if dist[i][j] >= 0 else " . ") for j in range(w)] for i in range(h)] viz.table(grid, {(r, c): "gold"}, f"visit ({r},{c}) at distance {dist[r][c]}") print("shortest path:" , dist[h - 1][w - 1])
```

C++

```
#include <iostream> #include <vector> #include <string> #include <queue> using namespace std; int main() { vector<string> maze = {"S..#.... " , " .#.#.##. " , " .#...#.. " , " .####.#. " , " ......#E"}; int h = maze.size(), w = maze[0].size(); vector<vector<int>> dist(h, vector<int>(w, -1)); queue<pair<int, int>> q; dist[0][0] = 0; q.push({0, 0}); int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1}; while (!q.empty()) { auto [r, c] = q.front(); q.pop(); for (int k = 0; k < 4; k++) { int nr = r + dr[k], nc = c + dc[k]; if (nr < 0 || nr >= h || nc < 0 || nc >= w) continue; if (maze[nr][nc] == '#' || dist[nr][nc] != -1) continue; dist[nr][nc] = dist[r][c] + 1; q.push({nr, nc}); } } cout << "shortest path: " << dist[h - 1][w - 1] << "\n"; return 0; }
```

## 2. DFS: flood fill

Count the islands on a map: when you find unvisited land, it is a new island; then DFS marks all land connected to it, so you will not count it again. DFS can be written with recursion or with an explicit stack (safer for big maps).

Python

```
import viz grid = ["11000" , "11010" , "00100" , "00011"] h, w = len(grid), len(grid[0]) label = [[0] * w for _ in range(h)] colors = ["gold" , "green" , "blue" , "pink" , "orange"] islands = 0 paint = {} for r in range(h): for c in range(w): if grid[r][c] == "1" and label[r][c] == 0: islands += 1 stack = [(r, c)] label[r][c] = islands while stack: y, x = stack.pop() paint[(y, x)] = colors[(islands - 1) % 5] viz.table(grid, paint, f"island {islands}: fill ({y},{x})") for dy, dx in [(1, 0), (-1, 0), (0, 1), (0, -1)]: ny, nx = y + dy, x + dx if 0 <= ny < h and 0 <= nx < w and grid[ny][nx] == "1" and label[ny][nx] == 0: label[ny][nx] = islands stack.append((ny, nx)) print("islands:" , islands)
```

C++

```
#include <iostream> #include <vector> #include <string> using namespace std; int main() { vector<string> g = {"11000" , "11010" , "00100" , "00011"}; int h = g.size(), w = g[0].size(), islands = 0; vector<vector<int>> label(h, vector<int>(w, 0)); int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1}; for (int r = 0; r < h; r++) for (int c = 0; c < w; c++) { if (g[r][c] != '1' || label[r][c]) continue; islands++; vector<pair<int, int>> st = {{r, c}}; label[r][c] = islands; while (!st.empty()) { auto [y, x] = st.back(); st.pop_ back(); for (int k = 0; k < 4; k++) { int ny = y + dr[k], nx = x + dc[k]; if (ny < 0 || ny >= h || nx < 0 || nx >= w) continue; if (g[ny][nx] != '1' || label[ny][nx]) continue; label[ny][nx] = islands; st.push _ back({ny, nx}); } } } cout << "islands: " << islands << "\n"; return 0; }

## World 9: Graph Grove

A graph is dots (nodes) joined by lines (edges): cities and roads, people and friendships, tasks and their order. Half of all olympiad problems hide a graph. Store it as an adjacency list: for every node, the list of its neighbours.

## 1. Topological order: what comes first

Tasks with "a must happen before b" form a directed graph with no cycles. Kahn's algorithm: count how many arrows point into each node; repeatedly take a node with count 0, output it, and remove its outgoing arrows.

## Python

```
from collections import deque import viz n = 6 edges = [(0, 1), (0, 2), (1, 3), (2, 3), (3, 4), (2, 5)] adj = [[] for _ in range(n)] indeg = [0] * n for u, v in edges: adj[u].append(v) indeg[v] += 1 q = deque([v for v in range(n) if indeg[v] == 0]) order = [] done = {} while q: u = q.popleft() order.append(u) done[u] = "green" viz.graph(n, edges, done, None, "order: " + " " .join(map(str, order)), directed=True) for v in adj[u]: indeg[v] -= 1 if indeg[v] == 0: q.append(v) print(*order)
```

C++

```
#include <iostream> #include <vector> #include <queue> using namespace std; int main() { int n = 6; vector<pair<int, int>> edges = {{0, 1}, {0, 2}, {1, 3}, {2, 3}, {3, 4}, {2, 5}}; vector<vector<int>> adj(n); vector<int> indeg(n, 0), order; for (auto [u, v] : edges) { adj[u].push _ back(v); indeg[v]++; } queue<int> q; for (int v = 0; v < n; v++) if (indeg[v] == 0) q.push(v); while (!q.empty()) { int u = q.front(); q.pop(); order.push _ back(u); for (int v : adj[u]) if (--indeg[v] == 0) q.push(v); } for (int i = 0; i < n; i++) cout << order[i] << (i + 1 < n ? ## 2. Dijkstra: shortest paths with weights

When roads have lengths, BFS is not enough. Dijkstra keeps a priority queue of (distance, node). Always finish the closest unfinished node (gold), then try to improve its neighbours. Finished nodes turn green; each label shows node:distance . Works when all weights are 0 or more. O(m log n).

Python

```
import heapq import viz n = 5 edges = [(0, 1, 4), (0, 2, 1), (2, 1, 2), (1, 3, 1), (2, 3, 5), (3, 4, 3)] adj = [[] for _ in range(n)] for u, v, w in edges: adj[u].append((v, w)) adj[v].append((u, w)) INF = float("inf") dist = [INF] * n dist[0] = 0 pq = [(0, 0)] done = {} while pq: d, u = heapq.heappop(pq) if d > dist[u]: continue done[u] = "green" for v, w in adj[u]: if d + w < dist[v]: dist[v] = d + w heapq.heappush(pq, (dist[v], v)) colors = dict(done) colors[u] = "gold" viz.graph(n, edges, colors, None, f"finish node {u} (distance {d}); labels show node:distance" , labels=[f"{i}:{' - ' if dist[i] == INF else dist[i]}" for i in range(n)]) print(*dist)
```

C++

```
#include <iostream> #include <vector> #include <queue> #include <tuple> #include <functional> using namespace std; int main() { int n = 5; vector<tuple<int, int, int>> edges = {{0, 1, 4}, {0, 2, 1}, {2, 1, 2}, {1, 3, 1}, {2, 3, 5}, {3, 4, 3}}; vector<vector<pair<int, int>>> adj(n); for (auto [u, v, w] : edges) { adj[u].push _ back({v, w}); adj[v].push _ back({u, w}); } vector<long long> dist(n, 1e18); priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<>> pq; dist[0] = 0; pq.push({0, 0}); while (!pq.empty()) { auto [d, u] = pq.top(); pq.pop(); if (d > dist[u]) continue; for (auto [v, w] : adj[u]) if (d + w < dist[v]) { dist[v] = d + w; pq.push({dist[v], v}); } } for (int i = 0; i < n; i++) cout << dist[i] << (i + 1 < n ? " " : "\n"); return 0; }

## 3. Union-find and Kruskal

Union-find keeps groups: find(x) returns the leader of x's group, union(a, b) merges two groups. With path compression it is almost O(1). Kruskal builds the cheapest network that connects every node (a minimum spanning tree): sort edges by cost and take each edge that joins two different groups.

Python

```
import viz n = 6 edges = [(0, 1, 4), (0, 2, 3), (1, 2, 1), (1, 3, 2), (2, 3, 4), (3, 4, 2), (4, 5, 6), (3, 5, 7)] parent = list(range(n)) def find(x): while parent[x] != x: parent[x] = parent[parent[x]] x = parent[x] return x total = 0 taken = {} for u, v, w in sorted(edges, key=lambda e: e[2]): ru, rv = find(u), find(v) if ru != rv: parent[ru] = rv total += w taken[(u, v)] = "green" viz.graph(n, edges, None, taken, f"take {u}-{v} (cost {w}), total {total}") else: viz.graph(n, edges, None, taken, f"skip {u}-{v}: already connected") print("total cost:" , total)
```

C++

```
#include <iostream> #include <vector> #include <tuple> #include <algorithm> #include <numeric> using namespace std; vector<int> parent; int find(int x) { while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; } return x; } int main() { int n = 6; vector<tuple<int, int, int>> edges = {{0, 1, 4}, {0, 2, 3}, {1, 2, 1}, {1, 3, 2}, {2, 3, 4}, {3, 4, 2}, {4, 5, 6}, {3, 5, 7}}; sort(edges.begin(), edges.end(), [](auto& a, auto& b) { return get<2>(a) < get<2> (b); }); parent.resize(n); iota(parent.begin(), parent.end(), 0); int total = 0; for (auto [u, v, w] : edges) { int ru = find(u), rv = find(v); if (ru != rv) { parent[ru] = rv; total += w; } } cout << "total cost: " << total << "\n"; return 0; }

## 2. 0/1 knapsack

## World 11: Range Tower

Prefix sums answer range questions fast, but break when values change. A Fenwick tree and a segment tree handle both updates and queries in O(log n). They appear in a huge number of advanced olympiad problems.

## Learn

## 1. The segment tree

Each node stores the sum of a segment. The root covers everything; each node splits its segment into two halves for its children; the leaves are single items. A query or an update touches only about 2·log n nodes. The highlighted nodes are the ones a query for positions 2..5 uses.

## Python

```
import viz a = [5, 3, 8, 6, 1, 4, 7, 2] n = len(a) tree = [0] * (2 * n) for i in range(n): tree[n + i] = a[i] for i in range(n - 1, 0, -1): tree[i] = tree[2 * i] + tree[2 * i + 1] parent = [-1] + [(i) // 2 - 1 for i in range(2, 2 * n)] labels = [str(tree[i]) for i in range(1, 2 * n)] viz.tree(parent, None, "every node = sum of its two children" , labels) def query(l, r): res = 0 used = {} l += n r += n + 1 while l < r: if l % 2 == 1: res += tree[l] used[l - 1] = "gold" l += 1 if r % 2 == 1: r -= 1 res += tree[r] used[r - 1] = "gold" l //= 2 r //= 2 viz.tree(parent, used, f"sum of positions 2..5 = {res}" , labels) return res print(query(2, 5))
```

```
#include <iostream> #include <vector> using namespace std; int main() { vector<int> a = {5, 3, 8, 6, 1, 4, 7, 2}; int n = a.size(); vector<long long> tree(2 * n, 0); for (int i = 0; i < n; i++) tree[n + i] = a[i]; for (int i = n - 1; i > 0; i--) tree[i] = tree[2 * i] + tree[2 * i + 1]; auto query = [&](int l, int r) { // positions l..r, 0-based long long res = 0; for (l += n, r += n + 1; l < r; l /= 2, r /= 2) { if (l & 1) res += tree[l++]; if (r & 1) res += tree[--r]; } return res; }; cout << query(2, 5) << "\n"; return 0; }
```

## 2. The Fenwick tree (binary indexed tree)

A shorter trick for prefix sums with updates. Position i stores the sum of a block whose length is the lowest set bit of i ( i &amp; -i ). Adding: climb with i += i &amp; -i . Prefix sum: descend with i -= i &amp; -i . Ten lines of code, used everywhere.

Python

```
import viz n = 8 bit = [0] * (n + 1) def add(i, x): while i <= n: bit[i] += x viz.cells(bit[1:], {i - 1: "gold"}, {"i": i - 1}, f"add {x} at block {i}") i += i & -i def prefix(i): s = 0 while i > 0: s += bit[i] i -= i & -i return s for pos, val in enumerate([5, 3, 8, 6, 1, 4, 7, 2], start=1): add(pos, val) print(prefix(6) - prefix(2))
```

```
#include <iostream> #include <vector> using namespace std; int n = 8; vector<long long> bit(n + 1, 0); void add(int i, long long x) { for (; i <= n; i += i & -i) bit[i] += x; } long long prefix(int i) { long long s = 0; for (; i > 0; i -= i & -i) s += bit[i]; return s; } int main() { vector<int> a = {5, 3, 8, 6, 1, 4, 7, 2}; for (int i = 0; i < n; i++) add(i + 1, a[i]); cout << prefix(6) - prefix(2) << "\n"; return 0; }
```

## 1. Euclid's gcd

gcd(a, b) = gcd(b, a mod b), and gcd(a, 0) = a. One of the oldest algorithms in the world, and O(log) fast. The least common multiple is a ÷ gcd(a, b) × b.

## 3. Modular arithmetic and inverses

Big answers are given mod M = 10 9 +7 (a prime). You may reduce after every + and ×. Division is different: dividing by a means multiplying by its inverse a M-2 mod M (Fermat's little theorem), computed with fast power. This is how contests compute combinations C(n, k) mod M.

Python

```
M = 10 ** 9 + 7 fact = [1] * 11 for i in range(1, 11): fact[i] = fact[i - 1] * i % M def inv(a): return pow(a, M - 2, M) n, k = 10, 3 print(fact[n] * inv(fact[k]) % M * inv(fact[n - k]) % M)
```

```
#include <iostream> #include <vector> using namespace std; const long long M = 1000000007; long long power(long long a, long long e) { long long r = 1; a %= M; while (e > 0) { if (e & 1) r = r * a % M; a = a * a % M; e >>= 1; } return r; } int main() { vector<long long> fact(11, 1); for (int i = 1; i <= 10; i++) fact[i] = fact[i - 1] * i % M; int n = 10, k = 3; cout << fact[n] * power(fact[k], M - 2) % M * power(fact[n - k], M - 2) % M << "\n"; return 0; }
