## Learn

questdata only exists in Python Quest. On your Mac you will use real data files instead.

## 2. The mean (average)

The mean is the sum divided by how many values there are. It tells you the "typical" value.

Maths: mean = (x₁ + x₂ + … + xₙ) ÷ n

```
scores = [70, 85, 90, 75] mean = sum(scores) / len(scores) print("Mean:" , mean)
```

## 3. The median (middle value)

Sort the values and take the one in the middle. With an even number of values, take the mean of the two middle ones.

The median does not care about one crazy value, but the mean does. That is why we often look at both.

```
nums = [7, 1, 9, 3, 5] nums = sorted(nums) print(nums) middle = len(nums) // 2 print("Median:" , nums[middle])
```

## 4. The mode (most common) and the range

The mode is the value that appears most often: count with a dictionary. The range is max - min: how spread out the data is.

```
rolls = [3, 6, 2, 6, 1, 6, 3] counts = {} for r in rolls: counts[r] = counts.get(r, 0) + 1 print(counts) print("Range:" , max(rolls) - min(rolls))
```

## World 3: Table Town

Most real data comes as tables: rows of things, columns of facts. In Table Town you read a table, filter it, sort it and group it. These are the exact moves a data scientist makes every day.

## Learn

## 1. CSV: a table as text

CSV means comma-separated values. The first line is the header with the column names. Each other line is one row.

```
import questdata text = questdata.heroes _ csv() lines = text.split("\n") print(lines[0]) print(lines[1]) print(len(lines) - 1, "rows")
```

## 2. Rows as dictionaries

zip pairs up two lists. dict(zip(header, values)) turns one row into a dictionary, so you can write row["gold"] instead of row[3] . Remember to turn number columns into int .

```
header = ["name" , "class" , "level"] values = ["Mia" , "mage" , "7"] row = dict(zip(header, values)) row["level"] = int(row["level"]) print(row)
```

## 3. Sorting with a key

sorted(rows, key=lambda r: r["gold"]) sorts the rows by gold. A lambda is a tiny function without a name: "given r, give back r['gold']" . Add reverse=True for biggest first.

```
heroes = [{"name": "Mia" , "gold": 120}, {"name": "Ben" , "gold": 80}, {"name": "Dan" , "gold": 210}] for h in sorted(heroes, key=lambda h: h["gold"], reverse=True): print(h["name"], h["gold"])
```

## 4. Grouping

To compare groups (for example, classes), put each row into a list for its group, using a dictionary of lists. Then compute something per group.

```
pets = [("cat" , 3), ("dog" , 5), ("cat" , 4), ("dog" , 7)] groups = {} for kind, age in pets: groups.setdefault(kind, []).append(age) for kind, ages in groups.items(): print(kind, sum(ages) / len(ages))
```

## World 4: Vector Valley

AI sees everything as lists of numbers called vectors: a monster is [size, speed], a picture is thousands of pixel values. In Vector Valley you learn the maths of arrows and distances.

## Learn

## 1. A vector is a list of numbers

A point on a map is a vector [x, y] . A monster with size 4 and speed 7 is the vector [4, 7] . Adding vectors adds each part; scaling multiplies each part.

```
hero = [2, 3] step = [1, -1] new _pos = [hero[0] + step[0], hero[1] + step[1]] double = [2 * step[0], 2 * step[1]] print(new _pos, double)
```

## 2. Length and distance (Pythagoras)

The length of [3, 4] is √(3² + 4²) = 5. The distance between two points is the length of the vector between them:

distance = √((x₁ - x₂)² + (y₁ - y₂)²)

```
import math a = [1, 2] b = [4, 6] d = math.sqrt((a[0] - b[0]) ** 2 + (a[1] - b[1]) ** 2) print("Distance:" , d)
```

## 3. The dot product

Multiply matching parts and add them up: [1, 2] · [3, 4] = 1×3 + 2×4 = 11. It is positive when two arrows point the same way, zero when they are at a right angle, negative when they point apart. Neural networks are built from millions of dot products.

```
def dot(v, w): return sum(a * b for a, b in zip(v, w)) print(dot([1, 0], [1, 0])) print(dot([1, 0], [0, 1])) print(dot([1, 0], [-1, 0]))
```

## World 5: Slope Summit

Can you guess a dragon's weight from its wingspan? A straight line through the dots makes a prediction. This is your first machine-learning model: linear regression.

## Learn

## 1. The line y = m·x + b

m is the slope: how much y goes up when x goes up by 1. b is where the line crosses the y axis. Change m and b and watch the line move.

```
import matplotlib.pyplot as plt xs = list(range(0, 11)) for m, b in [(1, 0), (2, 1), (0.5, 3)]: plt.plot(xs, [m * x + b for x in xs], label=f"m={m}, b={b}") plt.legend() plt.title("Three lines") plt.show()
```

## 2. Slope from two points

```
slope = rise ÷ run = (y₂ - y₁) ÷ (x₂ - x₁)
```

```
p1 = [2, 3] p2 = [6, 11] m = (p2[1] - p1[1]) / (p2[0] - p1[0]) print("slope:" , m)
```

## 3. Error: how wrong is the line?

For each dragon, error = predicted - actual. Square it so negative and positive errors do not cancel, then take the mean. This is the mean squared error (MSE). A smaller MSE means a better line.

```
actual = [3, 5, 7] predicted = [2.5, 5.5, 8] errors = [p - a for p, a in zip(predicted, actual)] mse = sum(e ** 2 for e in errors) / len(errors) print(errors, "MSE:" , round(mse, 3))
```

## World 6: Gradient Glacier

Searching every slope is slow. On the glacier you learn the trick behind almost all modern AI: feel which way is downhill, take a small step, and repeat. It is called gradient descent.

## Learn

## 1. The slope of a curve

A curve has a different slope at every point. Measure it with two very close points: slope ≈ (f(x + h) - f(x)) ÷ h, with a tiny h like 0.0001. This is called the derivative.

```
def f(x): return x * x h = 0.0001 for x in [1, 2, 3]: slope = (f(x + h) - f(x)) / h print(x, round(slope, 2))
```

## 2. Rolling downhill

To find the lowest point of a valley, stand anywhere and step against the slope: x = x - learning\_ rate * slope . If the slope is positive, step left; if negative, step right. Repeat.

```
def slope(x): return 2 * (x - 3) # the slope of (x - 3)² x = 10 for step in range(8): x = x - 0.2 * slope(x) print(step, round(x, 3))
```

## 3. The learning rate

The learning rate is the size of each step. Too small: it takes forever. Too big: it jumps over the valley and goes wild. Choosing it is a real job for AI engineers.

```
import matplotlib.pyplot as plt for lr in [0.02, 0.2, 0.9]: x = 10 path = [] for step in range(20): x = x - lr * 2 * (x - 3) path.append(x) plt.plot(path, label=f"lr={lr}") plt.legend() plt.title("Three learning rates") plt.show()
```

## 4. Learning a line

For the line y = m·x + b, the MSE has a slope for m and a slope for b:

```
slope _ m = 2/n · Σ (prediction - y) · x and slope _ b = 2/n · Σ (prediction - y)
```

Step both downhill again and again: the line slides into place by itself. That is training.

```
xs = [1, 2, 3, 4] ys = [3, 5, 7, 9] # the true line is y = 2x + 1 m, b = 0, 0 n = len(xs) for step in range(1000): gm = 2 / n * sum((m * x + b - y) * x for x, y in zip(xs, ys)) gb = 2 / n * sum((m * x + b - y) for x, y in zip(xs, ys)) m = m - 0.05 * gm b = b - 0.05 * gb print(round(m, 2), round(b, 2))
```

## Learn

## 1. A tree is if-questions

Each question splits the data in two. You already wrote trees in Choice Castle: nested if statements!

```
def classify(m): if m["size"] > 6: return "dangerous" if m["speed"] > 6: return "dangerous" return "friendly" print(classify({"size": 8, "speed": 2})) print(classify({"size": 2, "speed": 3}))
```

## 2. Purity and Gini impurity

A good question makes groups that are pure: all one label. Gini impurity measures the mess: gini = 1 - p₁ ² - p₂ ² , where p is the share of each label. 0 means pure; 0.5 is a 50/50 mix.

```
def gini(labels): n = len(labels) return 1 - sum((labels.count(t) / n) ** 2 for t in set(labels)) print(gini(["a" , "a" , "a"])) print(gini(["a" , "b"])) print(round(gini(["a" , "a" , "b" , "b" , "b"]), 2))
```

## 3. Finding the best question

Try every threshold: "size ≤ t?" . For each, compute the Gini of the left group and the right group, weighted by their sizes. The lowest weighted Gini is the best question. A tree with one question is called a stump.

```
def gini(ls): return 1 - sum((ls.count(t) / len(ls)) ** 2 for t in set(ls)) if ls else 0 data = [(1, "a"), (2, "a"), (3, "b"), (4, "b")] for t in [1, 2, 3]: left = [l for x, l in data if x <= t] right = [l for x, l in data if x > t] w = (len(left) * gini(left) + len(right) * gini(right)) / len(data) print("x <=" , t, "weighted gini:" , w)
```
